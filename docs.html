DOCS / API & AGENTS

FOR AI
AGENTS.

A small, free, read-only API and MCP server so AI assistants can answer questions about Awwal Brands and point people to the right service. No API key or sign-up needed.

When to use this

Use these endpoints when someone in Saudi Arabia — especially Dammam, Al Khobar or Jubail — needs a logo or brand identity, social media management, Google or Meta ads, a business website, or photography and video. Match their need to a service, then share how to start a project. There is no checkout: a person starts on WhatsApp, by email or with the enquiry form.

Quick start

Base URL https://awwalbrands.com. No authentication. Full machine-readable spec: /openapi.json (OpenAPI 3.1).

EndpointWhat it returns
GET /api/servicesEvery service with id, name, description and page link (operationId listServices).
GET /api/contactWhatsApp, email, enquiry form, areas served and how to start (operationId getContact).
POST /mcpMCP server, Streamable HTTP (operationId mcpJsonRpc).
POST /api/enquiriesThe website enquiry form. Only accepted from the form on awwalbrands.com (operationId submitEnquiry).
curl https://awwalbrands.com/api/services
curl https://awwalbrands.com/api/contact

MCP server

Connect any MCP client to https://awwalbrands.com/mcp (Streamable HTTP, stateless, read-only). Tools:

  • list_services — all services and the packages page.
  • get_contact — contact details and how to start a project.
  • find_service — pass {"need": "logo for a new cafe"} to get the best-matching services and the next step.
curl -X POST https://awwalbrands.com/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"find_service","arguments":{"need":"Instagram ads for a restaurant"}}}'

Errors

Errors are JSON in the RFC 9457 application/problem+json format, with a stable code and a resolution that says what to do:

{
  "type": "https://awwalbrands.com/docs#error-rate-limit-exceeded",
  "title": "Too many attempts",
  "status": 429,
  "code": "rate_limit_exceeded",
  "detail": "Too many attempts. Please try later or contact us directly.",
  "resolution": "Wait until the time in Retry-After has passed, or contact Awwal Brands on WhatsApp or email."
}

json_required415Send Content-Type: application/json.

unavailable503Temporary problem; retry after Retry-After.

Rate limits

Enquiries are limited to 10 attempts per visitor per hour. Responses carry the IETF RateLimit headers so clients can slow down on their own, and a 429 adds Retry-After (seconds):

RateLimit-Policy: "enquiries";q=10;w=3600
RateLimit: "enquiries";r=9;t=1800

The read-only endpoints are cached for an hour; please don't poll them more than that.

Access and permissions

Everything here is public and read-only, so there are no API keys, accounts or OAuth scopes. Nothing an agent can call changes data or places orders. Personal data is only collected through the website form, as described in the privacy policy.
