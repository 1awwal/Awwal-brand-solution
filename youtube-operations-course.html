Module 1Plan a searchable release0/2 sessions

Audience intent and topic selection

Session notes

Start with a specific problem a viewer wants to solve. Compare wording used in questions and search suggestions, then decide which audience and outcome the video serves.

Practice task Write three viewer questions and select one to turn into a video brief with an audience and outcome.

Titles, thumbnails and descriptions

Session notes

Make the title and thumbnail work together with one clear promise. Check legibility at phone size, write an accurate opening description and add relevant chapters where appropriate.

Practice task Create two title and thumbnail pairs for the same video, then compare their clarity at a small size.

Preflight and unlisted review

Session notes

Upload an unlisted copy and watch it after processing on a second device. Check speech, caption timing, credits, chapters, artwork, description links and intended audience settings.

Practice task Build a release checklist and record a timestamp and owner for every issue found.

Scheduling and community workflow

Session notes

Pick a release window appropriate to the audience. Confirm the calendar time zone, prepare a pinned comment with a relevant next step and define who will review comments after launch.

Practice task Create a schedule entry with an approval owner, release time and comment follow-up window.

Module 3Measure and improve the next release0/2 sessions

Read impressions, clicks and retention

Session notes

Compare videos with similar audiences and traffic sources. A high click-through rate and early drop may indicate a gap between packaging and the opening. Inspect the segment where viewers leave before choosing a change.

Practice task Use a sample analytics export to identify one packaging issue and one opening issue, and write the evidence for each.

Reporting and next experiment

Session notes

Keep one primary change per test where possible. Record baseline, comparison window and the metric you expect to move. Note any changes in traffic mix so the result can be interpreted fairly.

Capstone Produce a one-page report and schedule a follow-up video with a revised opening or thumbnail hypothesis.
