Module 1Build a show file0/2 sessions

Signal flow and scene layout

Session notes

Draw the route from camera and microphone through OBS to the audience. Set a canvas that matches your intended output and fit each source without stretching it. Reuse a single camera source across scenes so its settings stay consistent.

Practice task Build four scenes and switch through them in order without leaving an empty Program frame.

Audio routing and monitoring

Session notes

Route the main microphone or venue mixer to a dedicated channel. Mute duplicate desktop inputs, listen on headphones and leave enough headroom for louder speech. Identify a backup microphone and rehearse transferring to it.

Practice task Record 30 seconds of quiet and loud speech, then replay it and document any clipping, echo or doubled audio.

Encoding and destination checks

Session notes

Choose an output profile based on the destination and measured upload stability. Run a private test, inspect the actual return feed, and watch the encoder and network counters during motion and speech.

Practice task Write down the output resolution, frame rate and observed drop counters during a five-minute test.

Recording and backup cues

Session notes

Start a local recording and check free storage before going live. Keep a holding scene with a short message and assign one person to monitor the actual destination while the operator switches.

Practice task Disconnect a simulated source, take the holding scene, restore the source and review the local recording.

Module 3Deliver and recover0/2 sessions

Run of show and role assignments

Session notes

Mark opening, speaker entrance, cues, planned cutaways, break and close. Give the operator, audio monitor and destination monitor a way to share faults quietly. Assign each change to one owner.

Practice task Run a timed rehearsal with a second person calling cues and log any missed transition.

Incident recovery and client handover

Session notes

Switch to the backup path, confirm the return feed and document the time of any incident. Check the local file opens, copy it to a second location and supply a short handover note.

Capstone Deliver a five-minute show recording, a cue sheet and an incident log showing one simulated recovery.
