# Awwal Brand Solutions website

Open `index.html` in a browser to view the site. It is a lightweight static website with no build step. See [CLOUDFLARE.md](CLOUDFLARE.md) for publishing it with Cloudflare Pages and connecting a domain.

## Editing

- Update page content in `index.html` and Arabic copy in `script.js`.
- Adjust the approved palette and responsive layouts in `styles.css`.
- Replace imagery in `assets/` with approved Awwal project visuals.
- The email address `hello@awwalbrands.com` is an editable placeholder. The contact form validates in the browser and opens a prefilled email draft; it does not send submissions to a server.
- The supplied files did not include Fathimi or 29LT Bukra font files, so Arabic copy uses Noto Sans Arabic until the licensed brand fonts can be added.

## Deploying

This repository is ready for Cloudflare Pages. Connect the GitHub repository in Cloudflare Pages and use the settings in `CLOUDFLARE.md`.
